# Startup of the Year — Landing Page Exercise

A simple static web page built with HTML and CSS, including a header graphic and promotional page content.

## Repository structure

- `index.html` — page markup.
- `style.css` — styling and responsiveness.
- `header.jpg` — visual asset.

## Run locally

Open `index.html` in a modern browser, or start a local static server:

```bash
python -m http.server 5500
```

The repository is a front-end learning/portfolio exercise. It does not contain backend services, accounts, databases or production startup infrastructure.

## Skills demonstrated

HTML page structure, basic layout and styling, image placement and static website publishing.
